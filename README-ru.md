# Бекенд для дипломной работы для колледжа

## Что это и зачем это?
Репозиторий для бекенд-части дипломной работы в колледже.

В проекте можно увидеть упомянания, что это для фотостудии «Культ» (например в .pdf файлах сгенерированных библиотекой Maroto)\
Но это было сделано просто для удовлетворения требований диплома

## Планы на репозиторий
Скорее всего после сдачи диплома перестанет обновляться, хотя я был бы не против попробовать написать различные тесты, так как ни разу еще с ними не работал
## Дополнительная информация

Для разработки использовались:\
GoFiber, Gorm, Maroto, Swaggo, zerolog
